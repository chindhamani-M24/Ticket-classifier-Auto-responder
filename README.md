# 🎫 Interactive Customer Support Ticket Classifier & Auto-Responder

An intelligent Natural Language Processing (NLP) and Machine Learning project built with Python. This system automatically classifies incoming customer support messages by intent and urgency, and instantly generates context-aware automated draft responses.

Designed for seamless execution in **Google Colab** with an interactive command-line interface.

---

## 🚀 Features

* **Intent Classification:** Uses TF-IDF vectorization and Logistic Regression (`scikit-learn`) to categorize customer tickets into specific departments (*Billing, Account, Technical, Shipping*).
* **Urgency Scoring:** Predicts the priority level of incoming complaints (*Low, Medium, High*).
* **Automated Draft Responding:** Dynamically maps classified intents to professional, pre-approved customer service response templates.
* **Interactive Terminal Loop:** Allows users to input custom customer messages in real-time and view instant AI analysis and auto-replies.
* **Zero Complex Setup:** Automatically installs required dependencies and builds the ML pipeline on the fly.

---

## 🛠️ Tech Stack

* **Python 3.x**
* **pandas** (Data manipulation and dataset creation)
* **scikit-learn** (TF-IDF vectorization, Logistic Regression, and ML pipelines)
